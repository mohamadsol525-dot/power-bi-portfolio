### Project 03 — Sales & Business Performance Dashboard

A multi-page dashboard designed to explore sales performance from several business perspectives. The report contains nine pages covering:

1. **Menu & Navigation** — Navigate between dashboard pages.
2. **Sales Overview** — Review high-level sales indicators and performance.
3. **Customer Analysis** — Explore sales and purchasing patterns across customers.
4. **Sales Representative Analysis** — Review sales representative performance.
5. **Sales Type Analysis** — Compare sales types and channels.
6. **Decomposition Tree** — Investigate contributing factors behind selected sales metrics.
7. **Time Trend Analysis** — Explore changes in sales over time.
8. **Product Analysis** — Compare products and their contribution to sales.
9. **Branch Analysis** — Compare performance across branches and explore their locations.

The project demonstrates the use of interactive report navigation, visual analysis, and business-focused dashboard design.

## How to Explore the Projects

1. Open a project folder using the links above.
2. Review its `README.md` and dashboard screenshots, where available.
3. Download the `.pbix` file and open it in Power BI Desktop to explore the report interactively.

> **Note:** GitHub displays Power BI files as downloadable files; it does not run `.pbix` reports interactively in the browser.
